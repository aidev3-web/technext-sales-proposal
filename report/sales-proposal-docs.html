Tổng quanOverview

technext-sales-proposal biến 1 cái tên công ty thành 1 bản đề xuất bán hàng đầy đủ, song ngữ (VI/EN), pitch 3 dịch vụ của TechNext (Odoo ERP, AI, Social Media). Bạn không gọi tool nào trực tiếp — chỉ cần nói với agent bằng lời thường, nó tự chạy đúng 15 bước phía dưới.technext-sales-proposal turns one company name into a complete, bilingual (VI/EN) sales proposal pitching TechNext's 3 service lines (Odoo ERP, AI, Social Media). You never call a tool directly — just tell the agent in plain language, and it runs the 15 steps below itself.

Khái niệm chínhKey concepts

  • OrchestratorOrchestrator — 1 skill "điều phối" đọc bản đồ 15 bước, quyết định bước nào chạy khi nào, không tự chứa toàn bộ chi tiết.the coordinating skill that reads the 15-step map and decides what runs when — it doesn't hold every detail itself.
  • SubagentSubagent — 1 "nhân viên ảo" riêng biệt, được giao 1 phần nghiên cứu cụ thể, chạy song song với các nhân viên khác.a separate virtual worker assigned one specific research slice, running in parallel with the others.
  • checkpoint.json — file nhớ đã chạy tới đâu — cho phép chạy lại từ giữa thay vì làm lại từ đầu.the file that remembers how far a run got — lets you resume mid-way instead of starting over.
  • Citation (trích dẫn)Citation — mỗi số liệu/câu trích trong bản đề xuất phải kèm link nguồn thật — không bịa, không ngoại lệ.every number/quote in the proposal must carry a real source link — nothing invented, no exceptions.
  • Gate (cổng chặn)Gate — 1 bước có quyền dừng cả pipeline nếu dữ liệu chưa đạt, khác với 1 bước chỉ "auto" chạy xong là qua.a step that can stop the whole pipeline if the data isn't good enough — unlike an "auto" step that just runs through.

Trước khi dùngBefore you start

1. Có gì đưa hết1. Give it what you have

  • Tên công ty, website nếu có, ghi chú họp nếu có — không cần chuẩn bị gì thêm.Company name, website if known, meeting notes if any — nothing else to prepare.

2. Không cần biết code2. No coding needed

  • Toàn bộ tương tác là hội thoại bằng lời thường với Claude Code.The whole interaction is plain-language chat with Claude Code.

3. Chờ vài phút thật3. Expect real minutes, not seconds

  • Pipeline làm nghiên cứu thật, không phải điền mẫu — nên mất nhiều phút, không phải giây.The pipeline does real research, not template-filling — so it takes minutes, not seconds.

company-verifierXác thực pháp nhân qua GLEIFConfirms the legal entity via GLEIF
VàoIn: tên công tycompany nameRaOut: company-identity.json
  1. Tra GLEIF bằng filter[fulltext] — không dùng filter[entity.legalName] (cần khớp gần chính xác, hay bị miss với công ty thật).Queries GLEIF via filter[fulltext] — never filter[entity.legalName] (needs a near-exact match, silently misses real entities).
  2. Nếu kết quả mơ hồ, thử nhiều biến thể từ (ghép/tách, số ít/nhiều) trước khi báo "không tìm thấy".If results are ambiguous, tries several word-shape variants (compound/split, singular/plural) before concluding "not found".

Lưu ý & sự cố có thể xảy raNotes & possible issues

1. 1 section báo "mỏng/không xác thực"1. A section is flagged thin/unverifiable

Nguyên nhânCause Khách hàng thật sự ít hiện diện công khai — không phải lỗiThe client genuinely has little public footprint — not a bug
Xử lýFix Đây là thông tin thật, cứ để nguyên và giao hàng kèm ghi chú đóThis is real information — keep it and deliver with that note intact

2. Chi phí "$40" bất thường xuất hiện2. A surprising "$40" cost appears

Nguyên nhânCause Model không phải Claude (vd deepseek/gpt) xuất hiện trong 1 session gắn "claude"A non-Claude model (e.g. deepseek/gpt) shows up inside a session tagged "claude"
Xử lýFix Đây là bug trộn provider thật — kiểm tra thủ công trước khi báo giá cho kháchThis is a real provider-mixing bug — verify manually before quoting the client

3. Pipeline dừng ở "blocking_issues"3. Pipeline stops at "blocking_issues"

Nguyên nhânCause source-auditor tìm thấy trích dẫn sai/không xác thực đượcsource-auditor found a wrong/unverifiable citation
Xử lýFix Đây là gate hoạt động đúng — đợi agent liên quan sửa lại, không tự ép cho quaThis is the gate working correctly — wait for the owning agent to fix it, don't force it through

4. File giao ra vẫn dùng CDN/Mermaid cũ4. Delivered file still uses old CDN/Mermaid

Nguyên nhânCause File được dựng từ bản template cũ, trước khi template được sửaThe file was built from an old template copy, before the template was fixed
Xử lýFix Chạy lại Phase 3 (assembler) để dựng lại từ template mới nhấtRe-run Phase 3 (assembler) to rebuild from the latest template
