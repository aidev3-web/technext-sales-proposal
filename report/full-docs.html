Tổng quanOverview

technext-sales-proposal (đổi tên từ sales-proposal-skill) biến 1 tên khách hàng thành 1 trang đề xuất bán hàng đầy đủ cho TechNext — nghiên cứu công khai, rà soát chiến lược, và đề xuất cả ba mảng dịch vụ: Odoo ERP, AI Solutions, Social Media Marketing. Bạn không gọi tool nào cả — chỉ cần nói chuyện bình thường với Claude Code, nó tự nhận diện và chạy skill này.technext-sales-proposal (renamed from sales-proposal-skill) turns a client name into one complete TechNext sales proposal — public research, strategic due-diligence, and a pitch across all three TechNext service lines: Odoo ERP, AI Solutions, Social Media Marketing. You never call a tool directly — just talk to Claude Code in plain language and it recognizes and runs this skill.

Khái niệm chínhKey concepts

  • SKILL.md — file hướng dẫn chính, dạy Claude cách chạy đúng quy trình 5 phase bên dưới.the main instruction file, teaching Claude the 5-phase workflow below.
  • .cite — link trích dẫn trỏ thẳng tới nguồn thật, gắn ngay sau mỗi số liệu có nguồn.a citation link pointing straight at the real source, attached right after every sourced number.
  • .assess — nhãn "Đánh giá của Technext" cho mọi suy luận/ước tính không có nguồn — không được lẫn với fact.the "Technext assessment" tag for every unsourced inference/estimate — never mixed in with facts.
  • findings.json — file kèm theo, liệt kê từng fact + nguồn + độ tin cậy A–D, để bước sau nối vào Odoo qua MCP.the companion file listing every fact + source + A–D confidence grade, so a later step can load it into Odoo via MCP.
  • validate-proposal.py — script kiểm tra máy móc 11 điều bắt buộc, chạy trước khi giao (Phase 4a) — không thay được rà soát bằng judgment, chỉ bắt lỗi định dạng khách quan.the mechanical validator for 11 objectively-checkable rules, run before delivery (Phase 4a) — doesn't replace judgment-based review, only catches objective formatting errors.
  • CheckpointCheckpoints — chạy 1 phase riêng (vd chỉ Group B, hoặc chỉ Phase 4) thay vì cả pipeline — mỗi phase lưu output ra file riêng (-p1-group*.html, -p2-frontmatter.html) và theo dõi qua -checkpoint.json.run a single phase alone (e.g. just Group B, or just Phase 4) instead of the whole pipeline — each phase saves its output to its own file (-p1-group*.html, -p2-frontmatter.html) tracked via -checkpoint.json.
  • Biểu đồ & sơ đồCharts & diagrams — 19 biểu đồ Chart.js + 9 sơ đồ Mermaid bắt buộc, dùng đúng bộ helper (regChart/PAL/baseOpts/gridScale) port thẳng từ bản gốc full1, tự vẽ lại đúng màu khi đổi theme.19 required Chart.js charts + 9 Mermaid diagrams, built through helpers (regChart/PAL/baseOpts/gridScale) ported straight from the original full1, re-rendering correctly on theme toggle.
  • Trích dẫn kiểu hoverHover-card citations — di chuột/focus vào [n] hiện ngay thẻ xem trước (đoạn trích + tên miền), không cần bấm; trên di động chạm lần 1 để mở thẻ, chạm lần 2 để mở link.hover/focus on [n] shows a preview card (excerpt + domain) with no click needed; on mobile, first tap opens the card, second tap opens the link.

Cấu trúc đã được rút gọn: bỏ 6 mục ít giá trị (Why AI is Important, PESTLE, Porter's Five Forces, Modern Alternative Services, Appendix & Sources, Content Calendar), thêm 4 mục mới (Current Operations, Current Tools & SaaS, Sources & Citation, Meeting Minutes).The sidebar is auto-generated by JS from each <section>'s attributes — never hand-written links. This order and grouping is fixed for every client. The structure was recently trimmed: 6 lower-value items dropped (Why AI is Important, PESTLE, Porter's Five Forces, Modern Alternative Services, Appendix & Sources, Content Calendar), 4 new ones added (Current Operations, Current Tools & SaaS, Sources & Citation, Meeting Minutes).

Quy trình 5 phaseThe 5-phase workflow

Đúng như trong SKILL.md — bấm vào từng phase để xem chi tiết. Đã gộp lại từ 6 phase (Research → Xây khung → Viết → Lắp ráp → Rà soát) vì kiến trúc cũ chạy tuần tự qua quá nhiều giai đoạn, tốn 45 phút–2 giờ mỗi lần — không phải do số lượng agent, mà do số giai đoạn nối tiếp nhau. Mới: mỗi phase giờ chạy được riêng lẻ (checkpoint) — không bắt buộc chạy hết 5 phase mỗi lần, xem mục Checkpoint trong Phase 4a.Exactly as written in SKILL.md — click a phase to expand. Merged down from 6 phases (Research → Build frameworks → Write → Assembly → Review) because the old pipeline queued through too many sequential stages, taking 45 minutes–2 hours per run — not from agent count, but from the number of stages chained together. New: every phase can now run standalone (checkpoints) — you no longer have to run all 5 every time, see the Checkpoint note under Phase 4a.

✓Gắn .assess "Đánh giá của Technext"Tagging it .assess "Technext assessment"

✓Truy về đúng 1 nguồn gốc, ghi rõ trong findingTracing back to the one real origin, noting it in the finding
